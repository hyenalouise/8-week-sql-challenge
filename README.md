# 8 Week SQL Challenge

My solutions to [Danny Ma's 8 Week SQL Challenge](https://8weeksqlchallenge.com/), done as part of my data engineering learning journey.

**SQL engine:** Databricks SQL 

## Folder layout

Each case study folder has:

- `README.md`: the problem, ERD, each question with my query, result, and approach
- `schema.sql`: the dataset setup script
- `solutions.sql`: all my queries in one runnable file

## Ground rules for myself

- Try every question on my own before looking anything up.
- Write down what tripped me up, not just the final answer.
- Commit after each question or two, with clear messages.
- Practice using VS Code, terminal and Databricks.
